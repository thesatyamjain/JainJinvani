## 2024-05-14 - Vite Environment Variable Leak
**Vulnerability:** The VITE_ADMIN_PASSWORD was being read as a plaintext environment variable. In Vite, any environment variable prefixed with VITE_ is statically replaced with its value during the build process, thereby exposing the plaintext password to the public bundle.
**Learning:** Client-side bundles should never include plaintext passwords or secrets as environment variables, even if they are only used to verify an input on the client-side. The public bundler will expose them.
**Prevention:** Always hash the password and provide the hash as the environment variable (e.g., VITE_ADMIN_PASSWORD_HASH), then check if the hash of the user input matches the provided hash.
## 2024-10-18 - HTML Sanitization Bypass via Template/Noscript
**Vulnerability:** The custom HTML sanitization function using `DOMParser` relied solely on traversing elements to clean disallowed tags and attributes. However, elements like `<template>` and `<noscript>` can mask content, preventing standard traversal from interacting with their inner elements. When re-serialized, these masked elements could execute malicious scripts (Mutation XSS).
**Learning:** `DOMParser` treats the content of `<template>` tags by placing it in a separate `content` document fragment, and treats `<noscript>` contents uniquely depending on context, effectively bypassing standard `querySelectorAll('*')` tree traversal.
**Prevention:** Always pre-process and explicitly remove content-masking elements (like `<template>` and `<noscript>`) before iterating through the DOM tree for sanitization.
