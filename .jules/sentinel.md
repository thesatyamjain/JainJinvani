## 2023-10-24 - DOMParser Security Bypass via Non-Traversable Tags
**Vulnerability:** The custom `sanitizeHtml.ts` implementation failed to sanitize elements placed inside `<template>`, `<math>`, or `<svg>` tags. When iterating over `documentFragment.body.querySelectorAll('*')`, elements inside a `<template>` tag are parsed into a separate `DocumentFragment` and thus hidden from standard node traversal, creating an opportunity for Mutation XSS (mXSS).
**Learning:** `DOMParser.parseFromString()` handles certain tags uniquely. Simply iterating over all descendants of the parsed `body` using `*` selector is not sufficient to inspect the entire parsed document if context-shifting elements are present.
**Prevention:** Always proactively find and remove structurally dangerous or context-shifting elements (`template`, `noscript`, `math`, `svg`, etc.) using targeted queries (e.g. `querySelectorAll('template')`) *before* relying on generic recursive tree traversal logic to validate attributes and contents.
