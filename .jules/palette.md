## 2024-05-18 - Avoid committing build artifacts\n**Learning:** Running `pnpm run check` or `pnpm run build` will generate output artifacts in the `build/` and `public/` directories that are not fully gitignored. Be careful to omit these generated files when committing manual code changes.\n**Action:** Use `git status` to carefully review staged files before submitting, and use `git reset HEAD build/ public/` and `git checkout build/ public/` if build artifacts were accidentally staged.
